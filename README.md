# 우리 어디서 만나지

친구 약속을 위한 공유형 만남 장소 추천 Next.js 웹 프로토타입입니다. 방 링크를 공유하면 참가자들이 출발 정보와 귀가 장소를 함께 수정하고, `결과보기`에서 추천 역/주변 장소에 투표할 수 있습니다.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3000`을 엽니다.

운영 빌드는 아래처럼 확인합니다.

```bash
npm run build
npm start
```

## 구현 범위

- 링크 기반 공유 방: `/rooms/{roomId}`
- 월 선택, 낮/밤 선택, 취향 태그
- 참가자 자동 이름 생성, 출발시각/출발장소/교통수단/귀가장소 공동 수정
- Next.js Route Handler 기반 API와 SSE 실시간 동기화
- 후보 역 5개 추천, 참가자별 소요시간/도착예정시간 표시
- 후보 역 및 주변 장소 투표
- 지도 API 키 없이 동작하는 로컬 추천/지도 목업 엔진

## 참고

현재 데이터는 Next.js 서버 메모리에 저장됩니다. 서버를 재시작하면 방 데이터가 초기화됩니다. 실제 배포 버전에서는 DB 저장소와 카카오맵/네이버 지도 API 연동을 붙이면 됩니다.
