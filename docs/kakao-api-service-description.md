# 서비스 소개 및 카카오맵 API 활용 목적

## 서비스 소개

**우리.어디서.만나**는 여러 명이 각자 다른 위치에서 출발해 만날 때, 모두에게 공평한 중간 장소를 추천해주는 모임 장소 추천 웹 서비스입니다.

방을 만들고 카카오톡 등으로 링크를 공유하면, 참여자들이 각자의 출발 시각·출발 장소·교통수단을 입력합니다. 서비스는 이 정보를 바탕으로 참여자 전원의 평균 이동 시간, 환승 편의성 등을 계산해 가장 공평하고 합리적인 만남 장소(지하철역, 카페, 음식점 등)를 추천하고, 참여자들이 투표로 최종 장소를 정할 수 있도록 돕습니다.

- **핵심 기능**: 방 생성 및 공유 → 참여자별 출발 정보 입력 → 평균 거리/이동 시간 기반 만남 장소 추천 → 참여자 투표로 장소 확정
- **타깃 사용자**: 친구·동료 등 여러 명이서 약속 장소를 정할 때 "어디서 만날지" 조율하는 데 어려움을 겪는 일반 사용자
- **서비스 형태**: 로그인 없이 링크 공유만으로 참여 가능한 웹 서비스 (Next.js 기반)

## 카카오맵(로컬 API) 활용 목적

참여자가 출발 장소를 입력할 때, 자유 텍스트 입력 대신 **실제 존재하는 장소/지명을 검색해서 선택**하도록 하기 위해 카카오 로컬 API(키워드 장소 검색)를 사용합니다.

- **문제 상황**: 참여자가 출발 장소를 직접 타이핑하면 "강남", "강남역", "강남역 2호선" 등 표기가 제각각이라 이후 이동 시간·경로 계산의 정확도가 떨어짐
- **해결 방법**: 카카오 로컬 키워드 검색 API로 실시간 장소 검색 자동완성을 제공해, 참여자가 정식 명칭과 주소가 확정된 장소를 리스트에서 선택하게 함
- **활용 범위**: 참여자 등록 화면의 "출발장소" 검색에 한정 (서버 라우트에서 REST API 키로 프록시 호출, 클라이언트에는 키 노출 없음)

## 이용 시나리오 예시

1. 지수가 친구 3명과 만날 약속을 잡기 위해 방을 생성하고 카카오톡으로 링크를 공유한다.
2. 링크를 받은 친구들이 각자 접속해 출발 시각과 교통수단을 입력하고, "출발장소" 항목에서 카카오맵 장소 검색으로 자신의 출발지(예: "강남역", "판교테크노밸리")를 검색해 정확한 장소를 선택한다.
3. 전원의 입력이 완료되면 서비스가 참여자들의 평균 이동 시간과 접근성을 계산해 공평한 만남 장소 후보 목록을 추천한다.
4. 참여자들이 추천된 후보 중 하나에 투표하고, 득표가 가장 많은 장소로 최종 만남 장소가 확정된다.

## 요청 API

- 카카오맵 REST API 중 **로컬 - 키워드로 장소 검색 (`/v2/local/search/keyword.json`)**
- 서버 사이드(Next.js API Route)에서만 호출하며, 클라이언트에는 검색 결과(장소명·주소)만 전달합니다.
